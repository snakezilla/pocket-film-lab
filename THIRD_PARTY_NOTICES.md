## Tetrahedral interpolation

src/engine/lut.ts implements standard tetrahedral interpolation, written for this project. The scheme matches the MIT reference https://github.com/calvinsilly/Tetrahedral-Interpolation (no code copied).

## Raw2Film

https://github.com/JanLohse/raw2film (MIT). Studied for pipeline order and halation colour weights (red 1.0 / green 0.4 / blue 0). No code copied.

## Native RAW engine (ios/)

`ios/PocketFilmLab/Resources/LUTs/*.cube.bin` are generated by `tools/make_raw_lut.py` from Spectral Film LUT 0.18.0 (MIT, licence above; licence re-checked 2026-10-29 in the installed package metadata: `License-Expression: MIT`). Stocks: Kodak Vision3 250D 5207, Vision3 500T 5219 and Portra 400 negatives, each printed on Kodak 2383. The grain, halation, softness and white-balance code is written for this project. No Chromagraph material is used anywhere; Chromagraph sample photos were only measured, and copies are kept out of the repo (`references/local/`, gitignored).

Test images (not shipped, not committed): CC0 DNGs from raw.pixls.us, listed in `raw-engine/TEST-RAWS.md`, plus a copy of one with only its Orientation tag changed (made by `tools/fetch_test_raws.sh`).
